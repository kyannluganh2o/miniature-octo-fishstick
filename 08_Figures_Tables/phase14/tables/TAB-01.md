# TAB-01

| Parameter | Physical meaning | Required definition | Common incompatible definitions | Minimum information for comparison | Recommended use |
| --- | --- | --- | --- | --- | --- |
| NPR | Upstream-to-downstream pressure ratio controlling underexpansion | Numerator and denominator roles, locations, total/static type, absolute/gauge basis, and time/stage | Rail/chamber; plenum/ambient; instantaneous/nominal; gauge/absolute | Both pressures plus nozzle state, gas, ambient state, and transient stage | Only definition-complete, condition-faceted jet comparisons |
| Mach number | Speed relative to a specified acoustic state | Object (jet, incident shock, post-wave flow, relative flow, detonation front), reference frame, and sound-speed state | Incident-shock M_s; post-shock M; droplet-relative M_rel; detonation-front Mach | Velocity, sound-speed state, frame, location, and time | Keep separate axes/facets for different frames |
| Weber number | Aerodynamic/inertial stress relative to surface tension | Density, velocity, length, and surface tension with state and frame | Pre/post-wave density; gas/droplet-relative velocity; parent/fragment diameter | All four components and loading stage | Conditioned response map; never a universal threshold alone |
| Reynolds number | Inertial transport relative to viscous transport | Density, velocity, length, viscosity, phase, state, and frame | Gas or liquid viscosity; post-wave or freestream state | All components and thermodynamic state | Companion condition, not a substitute for the load history |
| Ohnesorge number | Liquid viscous resistance relative to capillary–inertial response | Liquid viscosity/density, surface tension, and length scale | Parent versus fragment scale; temperature-dependent properties | Liquid identity, temperature/state, and d definition | Material/scale facet for breakup comparisons |
| Loading duration | Time over which a specified pressure/slip load acts | Start/end events and whether interval is front passage, post-wave residence, or full forcing | Shock transit; compressed-gas residence; time to expansion arrival | Both events, time reference, and load variable | Conceptual or within-compatible-case only |
| Breakup time | Interval to a specified deformation or fragmentation event | Onset, first shedding, sheet rupture, or complete breakup plus normalization | Onset versus completion; dimensional time versus t* | Event definition, scale, imaging/model criterion | Event-specific values only |
| Signed ΔSOI | Ordered separation between pilot and main-fuel injection events | Target SOI minus reference SOI, fuel order, actual/electronic/hydraulic event, and unit | Opposite sign; crank angle versus time; command versus actual SOI | Both named events, sign convention, engine speed for conversions, operating point | Condition-faceted chronology tables/plots |
| L_E/L_D | Evaporation distance relative to a named detonation/reaction/refill scale | Evaporation endpoint and denominator physical length | Front height, cell width, induction length, refill length | Both lengths, chemistry, geometry, wave number, and residence definition | Within the reported strong-wave domain only |
