## Candidate Claim 1

Claim ID: PILOT-C016-C01

Claim: Shock-induced aerobreakup is described in two stages: early wave dynamics followed by airflow-driven breakup.

Evidence type: author_interpretation

Evidence summary: Wave imaging resolves reflected/transmitted/internal structures before induced-airflow deformation and fragmentation.

Source location: PDF p.29, Conclusions

Support type: author_interpretation

Value status: reported

Limitations: Stage boundaries are mechanistic, not a universal fixed time.

Potential review use: Supplies the canonical wave → loading → instability → breakup sequence.
