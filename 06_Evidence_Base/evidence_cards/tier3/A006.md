# A006 Tier3 Evidence Card

## Candidate Claim 1

Claim ID: T3-A006-C01

Candidate claim: Delaying the diesel pilot to create slightly premixed NG combustion greatly reduced PM, but stable low-PM operation required managing methane, NOx, pressure-rise, and cycle-variation tradeoffs.

Evidence type: reported result

Evidence summary: The optimized B75 point removed over 90% PM with about 2% efficiency improvement at similar NOx/methane, but increased cycle variation and peak pressure-rise rate.

Source locator: LOC-A006-0002

Support type: direct_observation

Limitations: Optimized at one mode; CFD did not correctly predict premixed NG ignition.

Relevant parameter IDs: PAR-A006-0001; PAR-A006-0002

Relevant process/event IDs: PROC-A006-001

Potential chapter role: Context for premixing-based soot control and its stability tradeoffs.
